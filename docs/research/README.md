# Research (historical)

This directory contains **historical research inputs and design explorations** —
the material that informed features while they were being designed. Nothing here
is guaranteed to describe the current implementation; several documents predate
major architecture changes (Core Data → SwiftData, feature scope shifts).

For current, accurate documentation see:

- [`../exercise-library.md`](../exercise-library.md) — the complete built-in
  exercise library (generated from seed data)
- [`../adrs/ADR-INDEX.md`](../adrs/ADR-INDEX.md) — accepted architecture decisions
- The repository `README.md` — feature overview

Documents are kept for the design context they capture. Treat any code-level
claims in them (entity fields, file names, counts) as snapshots of their time.
